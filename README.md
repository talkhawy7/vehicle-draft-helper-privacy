# Vehicle Draft Helper Privacy Policy

Effective Date: May 2026

## Overview

Vehicle Draft Helper is a browser extension designed to help automotive sales professionals capture vehicle listing information from supported inventory websites and prepare marketplace listing drafts.

This Privacy Policy explains what information may be collected, how it is used, and how it is protected.

---

# Information We Collect

Vehicle Draft Helper may collect and process the following information during normal extension functionality:

* Vehicle listing information such as:

  * vehicle title
  * price
  * mileage
  * photos
  * vehicle specifications
  * listing descriptions
* User authentication information used for account login
* Extension settings and locally stored draft information

The extension does NOT collect:

* health information
* financial payment information
* personal messages
* unrelated browsing activity

---

# How Information Is Used

Collected information is used only for the core functionality of the extension, including:

* capturing vehicle listing data
* preparing marketplace listing drafts
* managing saved vehicle drafts
* improving workflow functionality

User data is not sold to third parties.

---

# Data Storage

Some information may be temporarily stored locally in the user's browser storage in order to support extension functionality.

If cloud services are used for authentication or account management, data is transmitted securely using encrypted HTTPS connections.

---

# Third-Party Websites

Vehicle Draft Helper interacts with supported third-party websites selected by the user, including vehicle inventory and marketplace platforms.

This extension is not affiliated with or endorsed by Facebook, OfferUp, AutoTrader, or any other third-party platform.

---

# Data Security

Reasonable security measures are used to protect user information and transmitted data.

---

# Changes To This Policy

This Privacy Policy may be updated periodically. Continued use of the extension after updates constitutes acceptance of the updated policy.
